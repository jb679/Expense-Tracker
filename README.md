# Expense Tracker 💰

A beginner-friendly Python command-line application that helps users track expenses and view spending summaries.

## Features

- Add expenses
- Remove expenses
- Validate user input
- Calculate total spending
- Calculate average spending
- Find highest and lowest expenses

## Technologies

- Python 3

## Concepts Practiced

- Variables
- Lists
- While loops
- Conditional statements
- Exception handling
- User input
- Built-in Python functions

## Future Improvements

- Save expenses to a file
- Add expense categories
- Add a graphical user interface
- Store data in a database
